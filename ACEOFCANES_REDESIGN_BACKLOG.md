# aceofcanes.com Redesign Backlog

Source: UI/UX/accessibility review, July 2, 2026. A reference mockup implementing all tickets exists at `aceofcanes_redesign_mockup.html`. Ticket IDs below match the tagged comments in that mockup.

Context for Claude Code: this site is a static dashboard generated by a Python script and hosted on GitHub Pages. All CSS/JS is inline in the generated HTML. Changes should be made in the Python generator (templates/strings), not by hand-editing the published HTML. Before starting any ticket, locate the generator file and identify where the HTML template lives.

Priority key: P1 = high impact, do first. P2 = medium. P3 = polish.

## P1 Tickets

### UX-01: Cumulative ACE pace chart (signature feature)
Add an inline SVG line chart to each basin panel showing 2026 cumulative ACE vs. the 1991-2020 climatological average curve, with the current date marked.
- Data: compute daily climatological cumulative ACE from HURDAT2 (1991-2020 mean by day-of-year) once, cache as JSON; plot current season's cumulative ACE from existing data.
- Render as inline SVG in the Python generator (no charting library needed; a path with cubic segments or polyline is fine).
- Include `role="img"` and a descriptive `aria-label` summarizing current value vs. average pace.
- Show a "% of climatological pace" callout near the season ACE number.
- Acceptance: chart renders on both basin tabs, scales responsively (viewBox), readable on mobile, aria-label present.

### LAYOUT-01: Show category color legend once per table
Remove the per-storm intensity category legend from each expanded storm row. Render it a single time below the storms table.
- Acceptance: expanding any storm shows only that storm's details; exactly one legend per basin table.

### COLOR-01: Replace gradient text on season ACE numbers
Change the large season ACE values from background-clip gradient text to a solid accent color (the darker end of each basin gradient: Atlantic ~#ff7043, Pacific ~#00c2a0) with an optional subtle text-shadow glow. Keep gradients on the basin header bars/tabs.
- Acceptance: numbers are solid color, contrast ratio >= 4.5:1 against card background.

### COLOR-02: Raise muted text contrast
Audit all uses of the muted text color (currently in the #475569 range). Raise to ~#8b9bb0 or lighter so all small text meets WCAG AA 4.5:1 against its background. Check labels, sublines, timestamps, table headers, footer.
- Acceptance: no small text below 4.5:1 (verify with a contrast checker or axe DevTools).

### A11Y-01: Respect prefers-reduced-motion
Wrap the spinning hurricane logo animation (and any pulse/glow animations) in `@media (prefers-reduced-motion: reduce) { animation: none; }`. Also disable smooth scrolling under the same media query.
- Acceptance: with OS reduced-motion enabled, nothing on the page animates.

### A11Y-03: Keyboard-accessible expandable storm rows
Convert storm row expand/collapse triggers to real `<button>` elements with `aria-expanded` and `aria-controls` pointing at the detail region. Detail region uses the `hidden` attribute when collapsed.
- Acceptance: Tab reaches every storm row; Enter/Space toggles it; screen reader announces expanded/collapsed state.

## P2 Tickets

### LAYOUT-04: Merge "vs average" context into top stat cards
Add a subline to each stat card (Named Storms, Hurricanes, Major Hurricanes) showing the climatological average for the current date, e.g. "avg by Jul 2: 1.9". Remove the now-duplicated count comparisons from the insights list.
- Acceptance: no metric appears in both the stat cards and the insights list.

### LAYOUT-02: Group and prune the insights list
Restructure the flat 11-item insights list into groups: Pace (rank, % of pace), Notables (ACE leader, longest storm). Move lower-value items behind a native `<details>` "More stats" disclosure. Mark decorative emoji `aria-hidden="true"` or remove them.
- Acceptance: at most 4-5 insights visible by default; rest collapsed; no emoji announced by screen readers.

### LAYOUT-05: Similar Seasons card
Promote the "similar seasons" insight into its own card with the 3 matched years as chips linking to their anchors on history.html, each showing that season's final ACE.
- Acceptance: card renders with clickable year chips; removed from insights list.

### UX-04: Active storm pill
When any storm is currently active, render a status pill near the top of the page: pulse dot + "1 active storm: Tropical Storm Douglas (35 kt)" linking to that storm's row/basin. Pulse animation must respect reduced motion (covered by A11Y-01).
- Acceptance: pill appears only when a storm is active; clicking it switches to the correct basin tab.

### UX-03: Relative update time
Next to the UTC timestamp, add a client-side computed relative time ("2 hours ago"). Small inline JS, no library.
- Acceptance: both absolute UTC and relative time shown; relative time correct across timezones.

### UX-05: Shareable tab state
Sync the Atlantic/Pacific tab selection to the URL hash (#atlantic / #pacific) via history.replaceState, and restore it on load.
- Acceptance: visiting aceofcanes.com/#pacific opens the Pacific tab; refresh preserves the tab.

### A11Y-06: Visible focus indicators
Add a global `:focus-visible { outline: 2px solid <accent>; outline-offset: 2px; }` rule so keyboard focus is clearly visible on the dark theme for tabs, buttons, links, and storm rows.
- Acceptance: tabbing through the page shows a visible ring on every interactive element.

## P3 Tickets

### UX-02: "What is ACE?" disclosure polish
Replace "(tap to expand)" with a chevron indicator using a native `<details>/<summary>` element.
- Acceptance: works with keyboard and screen readers out of the box; no device-specific wording.

### A11Y-02: Theme toggle semantics
Ensure the light/dark toggle is a `<button>` with `aria-pressed` and an `aria-label` like "Switch to light mode" that updates on toggle.

### A11Y-04: Table sort semantics
Add `aria-sort` to the sorted column header. If sorting is interactive, the header content must be a button with an aria-label describing the current sort.

### A11Y-05: Cone image alt text
Ensure the NHC cone graphic alt text includes storm name and advisory timestamp, e.g. "NHC forecast cone for Tropical Storm Douglas, advisory 22:03 UTC July 2."

### COLOR-03: Reserve a status palette for classification
Define separate CSS variables for classification colors (Below Normal green, Near Normal yellow, Above Normal orange, Extremely Active red) distinct from basin accent colors, so Atlantic orange never collides with "Above Normal" orange. Use them for classification badges only.
