## Project Overview

ACE Tracker is a Python tool that tracks **Accumulated Cyclone Energy (ACE)** for Atlantic and Eastern Pacific hurricane seasons, generating Excel spreadsheets and HTML dashboards with historical data from 1991 onward.

## Critical Domain Knowledge

### ACE Calculation
- **Formula**: ACE = Σ(V²max) × 10⁻⁴
- **IMPORTANT**: Wind speeds are ALWAYS in **knots**, never mph
- ACE is only counted at **synoptic times**: 0000, 0600, 1200, 1800 UTC
- Only counts when storm status is: TS (Tropical Storm), HU (Hurricane), or SS (Subtropical Storm)
- Minimum wind for named storm: 34 knots

### Data Source - Tropycal Library
- **Current implementation**: Uses Tropycal library (replaced web scraping in migration)
- Tropycal provides HURDAT2 data from NOAA (official hurricane database)
- Tropycal basins: `'north_atlantic'` and `'east_pacific'`
- Provides complete storm lifecycle data including start/end dates for duration calculations

### NOAA Season Classifications
**Atlantic:**
- Below Normal: < 73 ACE
- Near Normal: 73-126 ACE
- Above Normal: 126-159 ACE
- Extremely Active: 159+ ACE

**Eastern Pacific:**
- Below Normal: < 73 ACE
- Near Normal: 73-126 ACE (different upper bound than Atlantic!)
- Above Normal: 126-159 ACE
- Extremely Active: 159+ ACE

## Architecture

### Main Module: ace_tracker.py (1322 lines)

**Configuration Section (lines ~48-92)**
- `BASINS` dict: Atlantic and Pacific basin configurations
- `SYNOPTIC_TIMES`, `ACE_STATUSES`, `MIN_NAMED_STORM_WIND`: ACE calculation constants
- `START_YEAR = 1991`: Historical data range
- `OUTPUT_FOLDER`: Relative path to data/ directory

**Key Functions:**
- `get_category(wind)`: Categorizes storm (TD, TS, Cat 1-5) based on wind speed in knots
- `is_major(wind)`: Returns True if Cat 3+ (≥96 knots)
- `finalize_storm(storm)`: Calculates final ACE, duration, max category for a storm
- `get_noaa_classification(ace, basin)`: Returns NOAA classification string
- `calculate_yearly_totals(storms)`: Aggregates annual statistics
- `find_similar_seasons(current_ace, yearly_totals)`: Finds historical analog years

**Data Flow:**
1. Fetch data via Tropycal library (tracks.TrackDataset)
2. Parse storms and calculate ACE at synoptic times
3. Generate 5-tab Excel workbooks (Summary, Storms, Historical, Yearly, Discord)
4. Create HTML dashboard with mobile-friendly styling
5. Output console summary

### Test Suite: test_ace_tracker.py (25 tests)

Tests organized into classes:
- `TestStormCategories`: Wind speed categorization (Cat 1-5, TS, TD)
- `TestMajorHurricane`: Major hurricane classification (Cat 3+)
- `TestACECalculation`: ACE formula accuracy
- `TestNOAAClassification`: Season classification thresholds for both basins
- `TestStormFinalization`: Duration, max category, ACE totals
- `TestYearlyTotals`: Annual aggregation
- `TestSimilarSeasons`: Historical analog matching
